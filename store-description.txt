Know what your machine is doing at a glance.

Plasmetrics is a compact system monitor for the Plasma 6 panel. Each metric shows as a label, a slim vertical bar and a value, so you can read your system's state without opening anything. Click it for a popup with history graphs, per-core load, clock speed, every drive grouped by physical disk, battery and network details, top processes, system info and uptime.

Metrics: CPU, memory, network, temperature, battery (level, wattage, voltage), world clock and disk.

Make it yours
- Show only the metrics you care about, and drag them into your preferred order
- Choose chart, value, or chart plus value for each one, and what the value shows: CPU percentage or clock speed, memory used, available or swap, battery level, wattage, voltage or time remaining
- CPU can also show one little square per core, colored green, orange or red by load, and the popup lists every core
- World clock: add any number of time zones, each with a short code (emoji welcome) and the hour difference to you
- Choose the battery, network interface, temperature sensor and disk to watch, including wireless mouse and keyboard batteries
- Pick colors from a fixed palette, set your font and sizes, switch °C/°F
- Vertical or horizontal panel labels

Light and simple. No background services. It reads /proc and /sys every couple of seconds. The only network request is an optional public IP lookup (api.ipify.org, at most every 10 minutes), which you can turn off.
